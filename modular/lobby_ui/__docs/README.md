# Selectable lobby UI

Модуль содержит две темы для лобби и редактора персонажа:

- `code/themes/terminal_*` — терминальный интерфейс BandaTroopers;
- `code/themes/classic_*` — классический интерфейс;
- `code/interface_controller.dm` — сохранение выбора, маршрутизация, музыка и пункт `Preferences.Menu`;
- `code/shared/character_preview.dm` — состояние боевого превью и отображение персонажа;
- `code/shared/character_localization.dm` — переводы и каноническое сопоставление вариантов;
- `code/shared/character_presentation.dm` — общие стили редактора и вспомогательных окон;
- `code/shared/accessory_picker.dm` — каталоги причёсок и растительности на лице;
- `code/shared/loadout_picker.dm` — карточный каталог лодаута;
- `code/shared/manifest.dm` — CRT-оболочка манифеста персонала без изменения его данных;
- `tools/check_modularity.ps1` — локальный static/build аудит отключаемости модуля.

Выбор хранится в корне общего preferences-savefile под ключом `banda_menu_interface`, поэтому не зависит от слота персонажа. Отсутствующее или неизвестное значение всегда означает терминальный интерфейс. Там же хранится `banda_terminal_effect_intensity`: `full` включает все эффекты, `reduced` оставляет разовые мягкие переходы без постоянного шума/мерцания, `off` отключает декоративные анимации, typewriter и terminal SFX. Неизвестное значение безопасно сбрасывается в `full`.

Обе темы используют единый `switch(current_menu)` в `code/modules/client/preferences.dm` и единый список вкладок из `get_banda_character_menu_tabs()`. Новую условную вкладку следует добавлять в этот список один раз, а её содержимое — в общий `switch(current_menu)`.

Терминальные музыка, звук кнопок, CRT-анимация и карточки причёсок включаются только через controller/theme route. Классическая тема использует стандартную lobby music и списки выбора причёски/растительности на лице.

Дополнительные эффекты терминальной темы остаются presentation-only: при первом входе блоки появляются каскадом, личное дело проходит трёхступенчатую авторизацию, заголовок показывает индикатор активности, а редкая слабая полоса помех проходит примерно раз в 31 секунду. Эффект сканирования портрета намеренно не используется. Refresh не повторяет boot/auth-сцену.

Реальная смена вкладки редактора получает короткий glitch; обновление значения внутри той же вкладки его не запускает. Печать миссии завершается несколькими миганиями блочного курсора и тихим подтверждением. Строки терминального манифеста проявляются сверху вниз без изменения данных. Звуки `terminal_startup.ogg`, `terminal_authorized.ogg` и `terminal_type_complete.ogg` хранятся в `assets/` вместе с остальными ресурсами Lobby UI.

При первом показе терминальное главное меню временно занимает 50% ширины окна BYOND. Редактор персонажа по-прежнему расширяет левую панель до 70%; возврат в меню снова устанавливает 50%, а выход из лобби или переход на классическую тему восстанавливает исходный пользовательский splitter. Стартовое раскрытие терминала из центральной полосы длится 1.44 секунды, связанная световая полоса — 1.56 секунды; повторные refresh не запускают интро заново.

Терминальный лодаут строится из исходных `GLOB.gear_datums_by_category` и `GLOB.gear_datums_by_name`: категории раскрываются внутри одного CRT-каталога, а каждый предмет показывается карточкой со спрайтом, canonical `display_name` и стоимостью. Сервер повторно проверяет datum по глобальному registry и применяет исходный `MAX_GEAR_COST`. Классическая тема сохраняет двухшаговый `tgui_input_list`.

`FlavorTextEditor` получает выбранную тему через `terminal_interface`. Терминальная ветка использует зелёную CRT-тему и русские presentation labels, но отправляет прежние ключи `general`, `head`, `face` и остальные через неизменённый action `set_flavor_text`. Классическая ветка сохраняет синюю тему и английские подписи.

Вспомогательные окна `Job Preferences`, `Job Assignment` и `Set Records` получают CRT-оболочку через helper-proc из `character_presentation.dm` только при выбранной терминальной теме. Их исходные `byond://` действия и классическая HTML-ветка остаются владельцами игровой механики и не заменяются.

Манифест терминального главного меню использует тот же CRT-каркас, текущие пользовательские цвета интерфейса и увеличенное окно таблицы. Состав, группировка и статусы по-прежнему целиком поступают из стандартного `GLOB.data_core.get_manifest(FALSE, TRUE)`; классическая тема и отключённый модуль показывают исходное окно `Crew Manifest`.

## Безопасная проверка модульности

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File modular/lobby_ui/tools/check_modularity.ps1
```

Скрипт проверяет отсутствие прямых implementation-ссылок вне модуля, выполняет DM-сборку с включённым Lobby UI, временно отключает только точную строку его include и выполняет вторую DM-сборку. Исходные байты `modular/modular.dme` всегда восстанавливаются в `finally`, после чего сверяется SHA-256. Include других модулей скрипт не изменяет.

Для быстрой проверки ссылок без компиляции:

```powershell
powershell -ExecutionPolicy Bypass -File modular/lobby_ui/tools/check_modularity.ps1 -StaticOnly
```
